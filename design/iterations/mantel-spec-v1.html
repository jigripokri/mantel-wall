1 · Direction

Warm-dark, editorial, one idea per zone. The surface is a warm near-black — a gallery wall at dusk, not OLED black — so it holds up in daylight and doesn't glow at 11pm. Newsreader (an optical-size serif built for large display setting) carries everything the family actually reads: the time, event titles, dates, the empty-state line. Instrument Sans does quiet wayfinding: section labels, times, meta. No cards, no shadows, no radii, no icons — hierarchy comes from size, weight, and one hairline rule under the header. The accent (a muted clay) appears exactly once per screen: the greeting. The palette is drawn from the room it hangs in: warm near-black for the slat-wall shadows, clay and ochre from the terracotta throw and marigold blanket, sage from the pillows, cream ink from the walls — the screen should read as one more framed piece on that wall, not a glowing rectangle.

2 · Tokens — Tailwind v4 @theme
@theme {
  /* surfaces */
  --color-surface:      hsl(26 12% 8%);   /* the wall */
  --color-surface-deep: hsl(26 10% 5%);   /* scrim base over photos */

  /* ink */
  --color-ink:          hsl(36 28% 91%);  /* titles, time, temp */
  --color-ink-dim:      hsl(32 10% 64%);  /* meta, event times, labels */
  --color-ink-faint:    hsl(30 8% 46%);   /* H/L, day labels — large text only */
  --color-ink-soft:     hsl(36 20% 82%);  /* secondary titles (coming up) */

  /* structure + accent */
  --color-line:         hsl(30 10% 20%);  /* header rule */
  --color-line-soft:    hsl(30 10% 16%);  /* row rules */
  --color-accent:       hsl(22 42% 68%);  /* clay — greeting only */

  /* person palette — matched lightness/chroma, spread hues */
  --color-person-clay:    hsl(16 45% 68%);
  --color-person-ochre:   hsl(42 48% 62%);
  --color-person-sage:    hsl(115 18% 60%);
  --color-person-harbor:  hsl(210 28% 68%);
  --color-person-heather: hsl(310 16% 68%);

  /* type */
  --font-display: "Newsreader", serif;
  --font-text:    "Instrument Sans", sans-serif;

  /* rhythm (logical px at 1920×1080) */
  --spacing-safe-x: 96px;   /* 5% of 1920 */
  --spacing-safe-y: 60px;   /* ≥5% of 1080, rounded up */
  --spacing-gutter: 120px;  /* between columns */
  --spacing-row:    26px;   /* agenda row vertical padding */
}

4 · Layout geometry at 1920×1080

Safe area: content inset 96px horizontal, 60px vertical (≥5% every edge). Inside it, three stacked zones:

Header (~330px): greeting/time/date left, weather right, both hanging from the top edge; one 1px rule closes the zone, 52px below the date.

Agenda (remaining ~570px): two columns, 1.55fr / 1fr, 120px gutter, starting 48px under the rule. Primary column holds up to 6 rows before capping (7th+ collapses into a final faint line: “+ 2 more”); secondary caps at 6. Rows are 1px-rule separated, 26px vertical padding — never clipped, always capped.

Morning ⇄ evening is one swap: which list occupies the wide column. The receding column renders at 60% opacity with the 34px row treatment; past events inside it fade to 45%. Same artwork, two moods. v2 todos take the lower half of the secondary column (under “Coming up”, same label style, person-colored dots, completed items at 40% opacity with no strikethrough) — the geometry already reserves the space.

5 · Person palette
clay
ochre
sage
harbor
heather

Five hues at matched lightness (~65%) and deliberately low chroma — they read as a family of muted pigments, not a legend. Assignment order maximizes hue distance for 2-person households (clay + harbor). Each clears 3:1 against the surface as an 11px dot, and the dot is always paired with the person's name — color is reinforcement, never the only signal.

6 · Legibility over photos (the v3 contract)

Strategy: a directional veil, not a panel. No backdrop blur (reads app-like and shimmers under Ken Burns drift), no contained card. Three layers:

① A full-bleed gradient scrim in surface-deep, 105°: 92% opacity at the left edge → 70% mid → 30% right — text lives left-heavy, the photo breathes on the right. ② A constant text-shadow (0 2px 28px surface-deep @ 55%) as insurance against a bright patch drifting under a headline. ③ Over photos, all ink steps brighten one notch (ink-dim → 72% L, hairlines become 22%-alpha white) so contrast is computed against the veiled photo, not the raw one.

The secondary column is dropped entirely in photo mode — one column of information over a photograph is décor; two is a dashboard. Tweak the veil strength with the scrim control and drop a real family photo into mockup 06 to stress-test.

Caption-column mode (mockup 02) needs no veil at all: the info column sits on solid surface, photos sit in their own panes separated by 8px mat lines in surface color — the same treatment as a framed multi-aperture print. Prefer it when the day has ≥3 events; save full-bleed for quiet days.

≈ 3.6 : 1

≈ 6.9 : 1

person dots

Non-text; all clear the 3:1 graphical floor. Sage is the tightest at 3.1.

Every text role is AA-or-better at its actual size; the two subtle steps (faint, dim) are reserved for roles that are already large. Matte + 10ft forgives low brightness, not low contrast — hence no step below 3.6:1 for anything readable.
